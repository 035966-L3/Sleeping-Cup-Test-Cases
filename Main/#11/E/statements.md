## 题目描述

交互库有一个 $1, 2, \ldots, 1000$ 的排列 $p$ 并拒绝让你直接访问。

你被允许做如下操作，次数不限：

- 向交互库支付 $C = \max\{I_2 - I_1, 0\} + 1$ 个金币，交换 $p$ 中你所指定的两项，其中：
    - $I_1$ 是操作前 $p$ 中逆序对的数量。
    - $I_2$ 是操作后 $p$ 中逆序对的数量。
- 操作结束后，交互库会给你结账，告知你 $C$ 的值。

你的手里有 $5 \times 10^4$ 个金币，请在不欠债的前提下将 $p$ 重排成升序 $\{1, 2, \ldots, 1000\}$。

## 交互方式

**本题是交互题。**

**本题提供额外头文件 `"sorting.h"`，你需要使用它进行交互：**

| 函数 | 描述 | 限制 | 可调用次数 |
| :-: | :-: | :-: | :-: |
| `int operate`$\\$`(int l, int r);` | 交换排列的第 $l$ 项和第 $r$ 项$\\$并得到 $C$ 的值 | $1 \le l < r \le 1000$ | 不限 |
| `void confirm();` | 当你认为完成了排序时，$\\$告知交互库排序完成 | 你必须在告知后$\\$终止程序 | $1$ |

**请在以下模板上答题。**

```cpp
#include <bits/stdc++.h>
#include "sorting.h"
using namespace std;
int main()
{
	int n = 1000, q = 5e4;
	bool ok = false;
	while (!ok)
	{
		int l = 1, r = n;
		// ...
		int c = operate(l, r);
		q -= c;
		assert(q >= 0);
		// ...
	}
	confirm();
	return 0;
}
```
